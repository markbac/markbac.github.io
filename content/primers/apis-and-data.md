# APIs and data primers

Systems talk to each other through interfaces, and the interface is a contract: once other teams or devices depend on it, it is expensive to change. These primers cover the common styles and formats.

- [REST APIs](rest-apis.md): resources, HTTP methods and status codes.
- [OpenAPI and AsyncAPI](openapi-and-asyncapi.md): describing request-response and event-driven interfaces.
- [Data formats](data-formats.md): JSON, YAML and Protocol Buffers.
- [CBOR and compact binary formats](cbor.md): encoding data for constrained devices and networks.

The [Guidelines](../guidelines/index.md) and [Standards](../standards/index.md) sections set the rules for API design here; these primers explain the ideas behind them.
