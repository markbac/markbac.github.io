# Programming and tools primers

Good tools remove friction and catch mistakes before anyone else sees them. These primers introduce the languages and tools that come up most often in this site's other sections.

- [Git practices](git-best-practices.md): commits, branches and history that help rather than hinder.
- [Static code analysis](static-code-analysis.md): finding bugs without running the code.
- [PlantUML and Mermaid](plantuml-and-mermaid.md): diagrams as text.
- [Python for automation](python-for-automation.md): scripting the repetitive parts of engineering.
- [Rust for systems programming](rust-for-systems.md): memory safety without a garbage collector.
- [A modern terminal](terminal-modernisation.md): Oh My Zsh, Oh My Posh and friends.

The [Tech Radar](../radar/index.md) shows which tools are recommended, and the [Guides](../guides/index.md) give step-by-step set-up instructions.
