# Security primers

Security is a property of the whole system, from the silicon in a device to the people who run the cloud platform. These primers introduce the cryptography, protocols, practices and standards that come up most often.

## Foundations

- [Cryptography basics](cryptography-basics.md): hashes, symmetric and public-key cryptography, MACs, key derivation and random numbers.
- [PKI and certificates](pki-and-certificates.md): how identities are issued, checked and revoked.
- [TLS and DTLS](tls-and-dtls.md): secure channels for streams and datagrams.
- [Post-quantum cryptography](post-quantum-cryptography.md): preparing for quantum computers.

## Building secure software

- [Secure coding practices](secure-coding-practices.md): habits that prevent whole classes of bug.
- [OWASP Top 10](owasp-top-10.md): the most common web application risks.
- [OAuth 2.0 and OpenID Connect](oauth-and-oidc.md): delegated authorisation and sign-in.
- [Zero trust architecture](zero-trust-architecture.md): no trust based on network location.

## Standards for connected products

- [ETSI EN 303 645](etsi-en-303-645.md): the baseline for consumer IoT security.
- [ISO/IEC 30141](iso-30141.md): a reference architecture for IoT systems.

The [Standards](../standards/index.md) and [Guidelines](../guidelines/index.md) sections set the security rules used here. The [Glossary](../glossary/index.md) defines the terms.
