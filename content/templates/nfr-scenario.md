# NFR scenario

Use this template to write a non-functional requirement as a testable quality scenario: the conditions, the event, the response and how it is measured. A requirement such as "the system shall be fast" cannot be verified; a scenario with a threshold can. The [requirements template](requirements.md) covers requirements in general.

## Template

```markdown
ID:           NFR-XXXX-000
Attribute:    Performance and timing
Environment:  Conditions under which the requirement applies
Stimulus:     The event that triggers the behaviour
Response:     What the system does
Measure:      How the response is measured, with a threshold
Verification: Test | Analysis | Inspection | Demonstration
```
