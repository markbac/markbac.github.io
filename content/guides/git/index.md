# Git

A practical guide to Git for developers: how it works underneath, the branching strategies teams use, and how to choose a version control system.

The rules for commits, branches and versions are in [EG-014](../../guidelines/version-control-and-versioning.md), and the [Git primer](../../primers/git-best-practices.md) is a shorter introduction.

| [Branching strategies](02-branching-strategies.md) | Trunk-based development, GitHub flow, GitFlow and release branches, back-porting, merge strategies, anti-patterns, monorepos |
| [Choosing a version control system](03-choosing-a-version-control-system.md) | What to weigh when picking or changing a version control system |
