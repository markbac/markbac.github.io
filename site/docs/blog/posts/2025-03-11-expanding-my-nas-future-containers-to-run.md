# Expanding My NAS: Future Containers to Run

With my Synology NAS already handling Docker workloads, I’m looking to expand its capabilities with some **new containers**. These will enhance **monitoring, automation, note-taking, development, and network management**. Here’s what’s on my list:

<!-- more -->

## **Monitoring & Network Tools**

* **Glances** – Real-time system monitoring for CPU, RAM, and storage.
* **Uptime Kuma** – Self-hosted status page for tracking service uptime.
* **NetAlert** – Notifies me when new devices connect to my network.
* **WatchYourLAN** – A lightweight LAN device monitor.

## **Automation & Utility**

* **Node-RED** – Visual programming for automating tasks.
* **Upsnap** – A simple Wake-on-LAN tool for remote device control.
* **Homarr**
* **Watchtower**

## **Productivity & Development**

* **Excalidraw** – A self-hosted collaborative whiteboard for quick diagrams.
* **Code-Server** – VS Code in the browser for lightweight development.
* **HedgeDoc** – Markdown-based collaborative note-taking.
* **Kanboard** – A Kanban board for tracking projects.
* **Blinko **
* **Trilium**

## **Other Useful Tools**

* **IT Tools** – A web-based toolkit for network diagnostics.
* **Gramps** – A genealogy database for mapping family history.
* **Reubah**

This will **expand my NAS into a full-fledged productivity and monitoring hub**. The key challenge? **Managing resources** while keeping everything lightweight and efficient.
